# CHHAM KAKNIKA PORTFOLIO

Modern personal portfolio built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Profile photo
Replace `public/images/profile-placeholder.svg` with your real photo. For example:
`public/images/profile.jpg`
Then update the `src` in `components/Hero.tsx` to `/images/profile.jpg`.
